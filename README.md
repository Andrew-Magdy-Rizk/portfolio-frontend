# Andrew Magdy Portfolio

A single-app portfolio built with Next.js 16, React 19, TypeScript, and Tailwind CSS.

## Structure

```text
src/
├─ app/          # App Router routes, root layout, and global styles
└─ features/     # Feature-owned UI and data
public/          # Static assets
```

## Commands

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
```
